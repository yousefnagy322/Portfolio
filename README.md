# Yousef Nagy — Flutter Developer Portfolio

A static portfolio website presenting Yousef Nagy’s Flutter development profile, experience, skills, courses, and project work.

## Highlights

- Profile, experience, technical skills, courses, and contact sections
- Featured project pages for HealthyNutrition, MOI Digital Reporting System, CancerScan, and the DEPI Hospital Complaint System
- Additional project pages for a shopping list, weather app, and coffee app
- Responsive navigation, a light/dark theme toggle, and keyboard/touch-enabled project image carousels
- Downloadable CV

## Stack

HTML, CSS, and vanilla JavaScript. There is no package manager or build step.

## Run locally

From the repository root, start a static file server:

```sh
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser. You can also open `index.html` directly.

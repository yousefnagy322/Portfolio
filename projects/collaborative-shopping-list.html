Collaborative Shopping List

A real-time collaborative mobile app that lets multiple people sync, update, and manage shared shopping items.

GitHub profileContact me

About the project

A shared list stays in sync as people add, categorize, and complete shopping items on their own devices.

Project highlights

  • Developed a real-time collaborative shopping list application allowing instantaneous updates across multiple user devices.
  • Integrated Firebase Firestore with real-time stream subscriptions for reactive state updates.
  • Implemented clean UI interactions with swipe-to-delete, item categorization, and completion status.
  • Structured codebase following Clean Architecture and BLoC pattern for predictable state and high maintainability.

Tech stack

  • Flutter
  • Dart
  • Firebase Firestore
  • Firebase Auth
  • BLoC/Cubit
  • Clean Architecture
